DRAGEN clarification: Compute for this study runs on a server (Biotech2024) that also has Illumina DRAGEN installed, but DRAGEN's FPGA-accelerated pipeline was not used for this SNP-array-based study — that hardware is built for sequencing data analysis. Imputation was done entirely by the external Michigan service; downstream analysis (PLINK/PLINK2, ADMIXTURE, sNMF, SAIGE) ran on ordinary CPU compute on the same server.

3. 1000 Genomes Reference Panel

Used throughout the global ancestry analyses (PCA, FST, PBS, ADMIXTURE) as the external comparison population.

SuperpopulationPopulations includedN
African (AFR)YRI, LWK, GWD, MSL, ESN, ACB, ASW671

South Asian (SAS)GIH, PJL, BEB, STU, ITU492
East Asian (EAS)CHB, JPT, CHS, CDX, KHV515
Americas (AMR)MXL, PUR, CLM, PEL348
Total (all 26 populations)2,548

Genome build: GRCh38 (matches the Uzbek cohort's build; verified directly against the reference panel's own file paths on the DRAGEN server). Note: this panel differs by 45 samples from the commonly-cited "2,504 unrelated" Phase 3 release — investigated and confirmed those 45 samples are not flagged as related to anyone in 1000 Genomes' own pedigree records, so this is not a relatedness contamination issue, just a different source-panel version. See the ADMIXTURE correction notes for the full verification.

4. Compute Infrastructure

  • Server: Biotech2024 (Illumina DRAGEN 4.5.4 / 4.4.4 installed; accessed via SSH tunnel)
  • Analysis tools: PLINK / PLINK2, ADMIXTURE v1.3.0, sNMF (R package LEA), SAIGE, VEP/Ensembl for annotation
  • Bulk data location: /staging/ALSU-analysis/ on the DRAGEN server

3

4
ID normalization & final QC — Step 5–6: 1,047 samples, 5.4M variants
5
Population genetics: local & global PCA, FST, PBS, ADMIXTURE (merged with the 1000 Genomes reference panel above) — Steps 7–14
6
ROH/IBD relatedness & RPL GWAS — Step 15–16
