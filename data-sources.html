Genome build: GRCh38 (matches the Uzbek cohort's build; verified directly against the reference panel's own file paths on the DRAGEN server). Note: this panel differs by 45 samples from the commonly-cited "2,504 unrelated" Phase 3 release — investigated and confirmed those 45 samples are not flagged as related to anyone in 1000 Genomes' own pedigree records, so this is not a relatedness contamination issue, just a different source-panel version. See the ADMIXTURE correction notes for the full verification.

What disease/phenotype "case"/"control" refers to is not stated anywhere and is currently unknown — confirmed with the study owner (2026-08-12) that this is genuinely new data, not a chip-failure rescan (an earlier external tracker's claim that it "replaces 2 failed ALSU chips" was a fabrication with no basis in the sample sheet — see uzbek-variant-frequency-explorer data-sources page, now corrected). Parked: not merged into any pipeline until its purpose is known.Identity-verified this session: genuinely distinct from the original 1,047-person cohort (no PI_HAT ≈ 1.0 matches, only plausible family relationships up to 0.634). Confirmed with the study owner (2026-08-12) to be population-genetics reference data, not part of the RPL (pregnancy-loss) cohort — it will feed the popgen track (Steps 7–14: PCA, FST, PBS, ADMIXTURE, ROH/IBD) only, never Step 16's RPL GWAS. A properly strand-aligned merge against the current spring2026 cohort was built and QC'd (mind 0.20 → PI_HAT≥0.98 dedup → geno 0.10, matching the original pipeline's own thresholds): 1,186 samples, 257,315 SNPs, at /staging/ALSU-analysis/spring2026/expanded_cohort/ConvSK_v2_expanded. Not yet imputed or pushed through downstream steps.

Fully incorporating GWAS2026-2 into the popgen track means re-running QC, merge, imputation, PCA, FST, PBS, ADMIXTURE, and ROH/IBD for the whole popgen side of the study — touching every published popgen number on this site, but never Step 16 (RPL GWAS), which stays scoped to the original cohort's phenotype data. That work is in progress with explicit sign-off. GWAS2026 (wave 1) stays out of scope entirely until its case/control purpose is known.

Note on completeness: /staging on the DRAGEN server is execute-only for the pipeline account — its top level cannot be listed or searched (ls/find both fail with permission errors). Every dataset on this page was found by following a specific reference in another file, not by an exhaustive scan. Treat this section as "everything found so far," not "everything that exists."

7. Data Flow Summary

1
Raw chip scan (Illumina iScan hardware) → GenomeStudio genotype calling
2
Sample & SNP QC (missingness, IBD dedup, chip-level checks) — Step 0–3
3
Imputation via Michigan Imputation Server (1000 Genomes Phase 3 reference) — Step 4
4
ID normalization & final QC — Step 5–6: 1,047 samples, 5.4M variants
5
Population genetics: local & global PCA, FST, PBS, ADMIXTURE (merged with the 1000 Genomes reference panel above) — Steps 7–14
6
ROH/IBD relatedness & RPL GWAS — Step 15–16
