Annotation of the highest-ranking SNPs on the NYGC reference (rebuilt 2026-10-04)

What changed. This step used to annotate the PBS “candidates” (8 in the original cohort, 5 in the expanded cohort, with the highlighted rs56186913 / uterine leiomyoma lookup). Those SNPs were artefacts of the old 1000G reference file; on the NYGC 30x reference there are no PBS candidates (maximum PBSUZB 0.070; step 10). Annotating nothing would be the honest minimum; instead the same four-source approach is applied to the SNPs that rank highest on the new data, so that the reader can see what they are. None of them is a selection candidate; see the discussion below.

1. Method

  • Positions and genes: Ensembl REST (overlap/region, GRCh38, queried 2026-10-04): overlapping genes, rsIDs and the dbSNP consequence type of the variant at exactly that position.
  • GWAS Catalog: EBI GWAS Catalog REST (singleNucleotidePolymorphisms/<rsID>/associations), up to two rsIDs per SNP. The query helper was checked with a positive control (rs1800414, a known pigmentation SNP, must return associations) before use, and every lookup records whether the call succeeded, so that “none listed” never stands for a failed request. 45 of 45 SNP lookups completed.
  • ClinVar: the clinical-significance field returned by Ensembl for the same variant.
  • Not done here: VEP consequence prediction with SIFT/PolyPhen, and GTEx eQTL lookups (done earlier for the withdrawn candidates). For a list of ancestry-informative SNPs they would add nothing a reader could interpret.

4. Summary

  • Of the 45 SNPs, 3 have a GWAS Catalog association listed: 10:81903459 (rs6584402): acute myeloid leukemia; 17:66222489 (rs8178843): blood protein amount, receptor-type tyrosine-protein phosphatase R measurement; 15:48955804 (rs28392847): aging rate.
  • Consequence types among the 45 SNPs (a SNP can have more than one): intron_variant 27, intergenic_variant 15, regulatory_region_variant 1, 5_prime_UTR_variant 1, non_coding_transcript_exon_variant 1. No SNP is annotated as missense or loss of function. 2 have a ClinVar-significance value in Ensembl (benign); none is pathogenic.
  • Interpretation. The top FST SNPs are ancestry-informative markers (Uzbek frequency between EUR and EAS; step 9), and the top PBS SNPs have maximum PBS 0.070; a gene annotation does not turn either into a selection finding. The mostly intronic and intergenic consequences are what one expects of common neutral variants.

6. Limitations

  • The lists are a small slice of the ranking, chosen by rank; annotation of a ranked top list is descriptive, not a test of enrichment.
  • Ensembl and the GWAS Catalog were queried on 2026-10-04; their content changes over time. Results are stored with the query date in the project folder (annot_cache.json, scripts annotate.py and annotate_gwas.py).
  • The GWAS Catalog lookup used rsIDs found at the exact position; SNPs without an rsID or with several overlapping records may be under-annotated.

1. Overview

The 8 PBS candidate SNPs identified in Step 10 (original cohort) are annotated using four complementary resources to assess their functional significance: Ensembl VEP for variant consequence prediction, GWAS Catalog for known disease associations, ClinVar for clinical pathogenicity, and GTEx for tissue-specific expression effects (eQTL). Section 0 above documents the expanded cohort's 5-candidate reannotation; the rest of this page (Sections 1–6) is the original cohort's 8-candidate results, preserved for comparison.

Goal: Determine whether the Uzbek-specific allele frequency shifts detected by PBS correspond to known functional variants, disease associations, or gene regulatory effects.

3. Annotation Pipeline

Annotations are retrieved via REST APIs using the Python script annotate_uzb_snps.py. Each API is queried sequentially with rate limiting to avoid throttling.

3.1 Ensembl VEP (Variant Effect Predictor)

Queries the Ensembl REST API to obtain rsID mapping, gene context, and predicted variant consequence:

# Ensembl VEP — POST batch request (up to 100 variants per request) POST https://rest.ensembl.org/vep/human/region Content-Type: application/json Payload: { "variants": ["9 104189856 . G C . . .", ...], "canonical": true } Returns: rsID, gene symbol, consequence type (missense_variant, synonymous_variant, intergenic_variant, etc.) Rate limit: ~15 requests/sec (0.07 s/request)

3.2 GWAS Catalog

Queries the EBI GWAS Catalog REST API by rsID to find known genome-wide significant associations:

# GWAS Catalog — lookup by rsID GET https://www.ebi.ac.uk/gwas/rest/api/singleNucleotidePolymorphisms/{rsid}/associations Returns: trait name, p-value, PubMed ID (top 5 hits per SNP) Rate limit: ~3 requests/sec (0.3 s/request)

3.3 NCBI ClinVar

Queries NCBI E-utilities to check clinical pathogenicity status:

# ClinVar — two-step lookup # Step 1: Search for ClinVar records by rsID GET https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi ?db=clinvar&term={rsid}[rs]&retmode=json # Step 2: Retrieve clinical significance GET https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi ?db=clinvar&id={clinvar_id}&retmode=json Returns: clinical significance, associated condition, ClinVar accession Rate limit: 3 requests/sec without API key (0.35 s/request)

3.4 GTEx eQTL

Queries the GTEx Portal API to check whether PBS candidates are expression quantitative trait loci (eQTL) in relevant tissues:

# GTEx — tissue-specific eQTL lookup GET https://gtexportal.org/api/v2/association/singleTissueEqtl ?snpId={rsid} &tissueSiteDetailId={tissue} &datasetId=gtex_v8 Tissues queried: - Whole_Blood - Liver - Artery_Aorta - Brain_Frontal_Cortex_Ba9 - Adipose_Subcutaneous Returns: target gene, p-value, effect size (dosage slope) Rate limit: ~5 requests/sec (0.2 s/request)

3.5 Running the Annotation Script

python3 annotate_uzb_snps.py
