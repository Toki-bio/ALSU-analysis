1. FROH covariate GWAS rerun

The primary RPL GWAS (AGE, BMI, PC1–PC3) planned to include FROH (inbreeding coefficient from runs of homozygosity) as a covariate but never joined it at run time. This reruns the full genome-wide scan and the PBS-candidate targeted test with FROH added, using the same phenotype and cohort as the primary run.

PBS candidates — FROH-adjusted RPL association

All 8 original PBS Tier-1 candidates remain non-significant for RPL association after FROH adjustment (p range 0.22–0.98) — consistent with the primary model. PBS and RPL-GWAS signal are, as expected, independent tracks.

2. Bootstrap confidence intervals on PBS candidates

1,000 individual-level bootstrap resamples (resampling with replacement within each population), Hudson's FST estimator, recomputing PBSUZB = (TUZB-EUR + TUZB-EAS − TEUR-EAS)/2 each time, for the 5 corrected PBS candidates (the current report's candidate set, not the earlier pre-bugfix 8-candidate list).

Result: all 5 candidates' 95% CIs exclude zero — the PBS signal is robust to individual-level sampling variance at every candidate locus.
Methodological note: the point PBS estimates here (Hudson's estimator, computed independently from genotypes) differ slightly in magnitude from the report's published PBS table (e.g. 2.845 here vs. 2.786 published for chr12:125,520,190) because a different, standard FST estimator was used for this robustness check rather than reproducing the original pipeline's exact formula. Both agree on direction, relative ranking, and — the point of this analysis — that the signal survives resampling.
