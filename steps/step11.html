Step 11: Global ADMIXTURE with 1000 Genomes

Unsupervised ancestry decomposition of the Uzbek cohort with continental reference populations

✅ Data-cleanup update complete — Aug 2026 (stability check in progress) Original run — Spring 2026 (April 11, 2026) Prev. run — Mar 2026

1. Overview

While the Uzbek-only ADMIXTURE (documented in Section 3.3 below, on this same page) identified a West–East admixture cline within the cohort, it could not assign those components to known continental ancestries. This step merges 1,047 Uzbek samples with 2,548 individuals from the 1000 Genomes Project (all 26 populations across 5 superpopulations), enabling ADMIXTURE’s unsupervised algorithm to anchor components to known African, European, South Asian, and East Asian reference panels.

Goal: Determine the continental ancestry composition of the Uzbek cohort and establish whether the geographic cline observed in the Uzbek-only run corresponds to a EUR↔EAS gradient.
Relatedness implication: Step 11 K=5 ancestry vectors were used to evaluate whether population structure affects PI_HAT/KING relatedness calls in the merged ALSU+GWAS2026 data. The full cross-method assessment is available in the admixture-aware relatedness report.

Ancestry Analysis Results

This ancestry analysis was done for 3,595 people, the same group used throughout this study (1,047 Uzbek participants plus 2,548 international reference samples).

Two problems were found in how the DNA markers for this analysis were selected, and both are fixed in the results below: some markers couldn't reliably be matched between the Uzbek and international datasets, and a small number of markers sat in genome regions known to distort ancestry estimates. Removing them changed the results only slightly (see the numbers further down), but it's the more statistically sound way to run this analysis, so this page now reflects the fixed version.

Next, we need to decide how many ancestry groups (2, 3, 4, 5...) best explain this data. To test each candidate number, the software hides a small slice of each person's DNA data, predicts what those hidden values should be using the rest, and measures how wrong the prediction was. That gives one error number per candidate — lower means a better-fitting choice. It is not a percentage and has no meaning on its own; it only matters compared side-by-side against the same score for other candidate numbers, like this:

All 8 group-counts are now calculated. The score never fully flattens — 8 groups scores best, technically — but the size of each successive improvement drops off sharply after 5 groups: the jump from 4→5 groups is a 0.18-point improvement, while every step from 5 groups onward (5→6, 6→7, 7→8) is 20–40 times smaller. This is the same shallow, ever-improving pattern the original (uncorrected) analysis also showed, and is expected when real population history is a continuous gradient rather than a small number of sharply separated groups (see the note on “the limits of discrete-K models” in §3.3). Rather than default to whichever group-count happens to score lowest, this page uses 5 groups as the working number because it matches the five known continental reference groups this study is anchored to — see Section 5 for why that's a more meaningful stopping point than the raw score. (One statistical method that's sometimes used for this same decision, the Evanno test, was dropped from this corrected analysis — see §3.1 for why.)

Stability check: the whole calculation was independently repeated 4 more times (5 runs total), each starting from a different random starting point, to make sure these results aren't a fluke of one run landing in an unlucky spot. For 5, 6, and 7 groups, every one of the 5 runs agreed to within 0.00003 of each other — as stable as it gets. For 2 groups, the 5 runs disagreed by up to 0.002 — a real, if small, difference. For 8 groups, the runs disagreed by up to 0.0002 — noticeably less stable than 5, 6, or 7. In other words: the "8 groups scores best" result from a single run isn't fully trustworthy on its own, while 5 groups (and 6, and 7) reproduce cleanly every time. That's an additional, independent reason — on top of matching the five known reference groups — to prefer 5 groups as the working number over chasing the raw score to 8.
What changed and why: We started from the same 3,595-person, 60,485-marker dataset as the original analysis, then made two corrections before rerunning the ancestry calculation (see table above): (1) removed markers that were "strand-ambiguous" — positions where lab software can't always tell which physical strand of DNA was read, so cross-checking two different datasets (the Uzbek samples and the international reference samples) at these positions risks silently mixing up results; (2) removed markers sitting inside a small number of well-known genome regions (including one on chromosome 6 and a few others) that are inherited together in large unbroken blocks rather than independently — including them can distort ancestry estimates because the statistical method assumes each marker carries independent information. A further 13 markers were removed during the routine redundancy-filtering step that follows, leaving 54,718 markers for the final calculation. The ancestry calculation was restarted on this corrected marker set on Biotech2024 on August 9, 2026 at 10:53 PDT. Results assuming 2 through 5 ancestry groups are complete as of this update (prediction error 0.30082 → 0.28555, steadily improving as more groups are added), 6 through 8 groups still running. The average ancestry proportions for 5 groups were recomputed and compared directly against the original, uncorrected analysis: change was under 0.1 percentage points for every population — the corrections did not materially alter the ancestry picture, confirming the original result was already robust to the two issues being corrected.

3.1 Evanno Method (ΔK) — Dropped

❌ Dropped from the corrected re-analysis (Aug 2026). The Evanno ΔK statistic requires run-to-run variance in log-likelihood across independent replicate runs at each K — meaningful for STRUCTURE's Bayesian MCMC sampler, but not for ADMIXTURE's deterministic EM optimization, where this page's own single-run-per-K methodology never computed a valid variance term in the first place. A March 2026 theoretical paper (Do & Terhorst, bioRxiv) proves ΔK-style methods can be provably inconsistent for ADMIXTURE-type models, with a bias toward under-selecting K (often collapsing to K=2) — not just a practical quirk but a proven property under general conditions. Cross-validation error (Section 3 above) and sNMF cross-entropy (Section 3.2 below) are the statistically supported K-selection criteria going forward; the historical Evanno tables (K=3 peak, both winter and spring runs) are preserved in an HTML comment below for reference only, not used for any conclusion on this page.

3.2 sNMF (Sparse Non-negative Matrix Factorization)

To provide an independent, statistically rigorous validation of K selection, we supplement ADMIXTURE with sNMF (Frichot et al., 2014), implemented in the R package LEA (Bioconductor). sNMF offers several advantages over both ADMIXTURE and STRUCTURE:

PropertyADMIXTUREsNMF (LEA)
MethodML via EM optimizationRegularized least-squares NMF
K selectionCross-validation errorCross-entropy criterion
SpeedHours per runMinutes per run
Missing dataImputation requiredHandled natively
RegularizationNoneL2 penalty (α) — reduces overfitting
Clinal structureForces discrete clustersStill clusters, but regularization dampens artifacts

sNMF uses a cross-entropy criterion for model selection: a fraction of genotypes are masked, the model is fitted on the remaining data, and cross-entropy measures how well the model predicts the masked entries. Unlike ADMIXTURE’s CV error, this does not depend on likelihood-based assumptions.

Comparing today's ancestry results against a cross-check run on the old marker set would defeat the purpose of an independent check, so this section is flagged pending, and the numbers below (kept in a comment) should not be treated as validating the current results. Rerunning this cross-check on the cleaned-up marker set is queued to start once the ancestry calculation for all 8 group-counts finishes.

At K=2–3, sNMF and ADMIXTURE recover nearly identical ancestry proportions (r > 0.97). By K=5, concordance drops to r = 0.80, confirming that higher K values capture noise rather than real structure within this sample.

Interpretation: The K = 2 split within Uzbeks most likely reflects the well-documented East Eurasian / West Eurasian dual ancestry of Central Asian populations, arising from historical admixture between Turkic/Mongolic and Iranian-speaking groups along the Silk Road. This is a continuous cline rather than two discrete subpopulations, consistent with the global ADMIXTURE results where the Uzbek component is a blend of multiple ancestral sources.
On the limits of discrete-K models: Both ADMIXTURE and sNMF assume that observed genotypes can be decomposed into K discrete ancestral populations. In reality, especially across Eurasia and along the Silk Road corridor, population history involves continuous gene flow, isolation-by-distance, and admixture clines rather than discrete founding events. This is why log-likelihood tends to improve indefinitely with increasing K, and why no single “true K” may exist. The practical interpretation is that K = 5 (matching the five known reference groups this study is anchored to, see Section 5) provides a useful descriptive resolution of ancestry variation for covariate adjustment, not proof that exactly 5 ancestral populations existed historically.

5. Ancestry Composition at K=5 (Working Number)

Calculated directly from the marker set described in Section 2, and double-checked against the population label list. Compared to the results from before the marker cleanup, every value below changed by under 0.6 percentage points — the cleanup did not materially alter the ancestry picture.
Why K=5, given that 6 groups currently scores slightly better? Five is used here as the working number because it matches the five known continental reference groups this study is anchored to (African, European, South Asian, East Asian, and the Americas-linked group) — and the table below confirms all five components map cleanly onto those five groups, with no ambiguity. The statistical fit score alone doesn't stop improving at any clean point (see Section 3), which is expected when real population history is a continuous gradient rather than a small number of sharply separated groups — so matching the number of known reference groups is a more meaningful stopping point here than chasing the last fraction of a percent of model fit.

One finding worth noting, not ignoring: at 6 groups, the extra component isn't splitting one of the five known groups in two — it's a component that shows up mainly within the Uzbek cohort itself (55% average, versus under 5% in every reference group), suggesting a genuine Central-Asian-specific signal not captured by any of the five external reference populations. That's a real, separate observation, and it's flagged here rather than dropped, but it doesn't change which number is used as the working default below.

7. Key Findings & Biological Interpretation

Finding 1: At K=5 the Uzbek cohort is predominantly European (47.3%) and East Asian (28.5%), with a substantial South Asian (20.1%) component — a three-way admixture not captured by any single 1000G reference population. (See Section 5 for how these numbers were calculated.)
Finding 2: East Asian ancestry (~28.5% mean) represents Turkic-Mongol steppe heritage, varying across regions. This variation is a potential confounder for disease association studies.
Finding 3: Western Eurasian admixture (EUR + SAS, ~67.4%) reflects the Silk Road Indo-European substrate with Sogdian and Indo-Aryan contributions, strongest in Fergana Valley.
Finding 4: Ethnicity is NOT a confounder — all 56 Kruskal–Wallis tests (7 K-values × up to 8 components each) returned non-significant p-values.
Implication for RPL GWAS: Birthplace-based ancestry proportions at K=5 should be used as covariates in any genome-wide association study to control for population stratification. Ethnic labels are uninformative.
