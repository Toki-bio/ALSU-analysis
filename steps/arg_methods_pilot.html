Ancestral Recombination Graph Methods — Pilot

Applicability of tsinfer+tsdate, SINGER, and ARG-Needle to the ALSU array cohort, and a real chr22 pilot run

Pilot — 2026-09-20 DRAGEN Biotech2024

1. What an ARG adds beyond Fst/PBS/ADMIXTURE

An ancestral recombination graph (ARG) reconstructs the genome-wide genealogy underlying a cohort — which samples share a recent common ancestor, where, and how long ago — rather than the allele-frequency snapshots that Fst, PBS, and ADMIXTURE all rely on. It adds a genuine time axis: effective population size through time (Ne(t)), divergence times between populations, and — most directly relevant here — corroborating genealogical evidence for selection at the loci already flagged by PBS (the chr9/chr18 loci, and the 5 PBS candidates): an unusually recent common ancestor among carriers of a candidate variant is independent support for selection, on top of the allele-frequency-based PBS signal.

ARG-Needle's minimum validated sample count (~300 sequences) is from Wang & Palamara, "The era of the ARG" (arXiv:2310.12070).

Real problems hit and fixed, for the next run

  1. Neither arg-needle-lib nor arg-needle (the CLI, entry point infer_args) were installed anywhere on DRAGEN — both installed cleanly via pip install --user arg-needle-lib arg-needle (pulls in ASMC decoding-quantity dependencies automatically).
  2. infer_args --mode array requires --num_snp_samples (haploid count) explicitly — omitting it fails deep inside the C++ layer with an opaque stoul error, not the documented validation message.
  3. The genetic map must be 4 columns, tab-separated: chromosome, SNP ID, cM, bp position — a 3-column map (ID, bp, cM) fails with the same opaque error.
  4. Duplicate physical positions in TOPMed-imputed data (multiple SNP IDs at the same bp, 18 of 92,704 chr22 sites here) must be removed from the .haps and .map files in lockstep, matched by row position — filtering by SNP ID alone silently fails when an ID also repeats.
  5. Confirmed hard floor: ARG-Needle's CSFS requires ≥300 haploid samples. A 98-haploid attempt failed explicitly: "SNP with ID rs117578132 has 98 non-missing individuals, but the CSFS requires at least 300." This empirically confirms the ~300-sequence minimum cited in the literature (§2 above) against our actual data.
  6. Threading rate observed: ~20–21 seconds per haploid sample on chr22 (92,686 SNPs) at 320 total haploid samples — roughly linear in sample count, so a full-cohort run (2,512 haploid) on one chromosome is a multi-hour job, and genome-wide is substantially longer. Not a "run it and check back in five minutes" task at full scale.

4. Next steps

  1. Fit or source a Uzbek/Central-Asian-appropriate demographic model for normalization, rather than the bundled CEU default, before treating Ne(t) or TMRCA outputs as calibrated.
  2. Extend the pilot to the full popgen cohort (n=1,256) on chromosomes containing the PBS candidates and the chr9/chr18 loci, to test for genealogical corroboration of the existing selection signals — the direct scientific payoff of this method.
  3. Consider tsinfer+tsdate as an independent cross-check on the same data once a genome-wide run exists to compare against.
